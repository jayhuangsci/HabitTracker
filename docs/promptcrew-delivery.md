# PromptCrew 分批交付记录

## 第一批：目录与权限

已实现独立 Core/API、EF Core SQLite 迁移、项目/员工/任务链 CRUD、项目范围密钥与撤销、版本号校验和 OpenAPI。

验证：5 个 API 集成测试通过；构建零警告。存储与原训练数据库分离。限制：暂无登录账户、删除与云同步；创建项目和签发密钥由管理员完成。

## 第二批：记录与历史

已实现原始输入保留、员工定义快照、不可变父节点、分支、输入修订、同项目跨链引用、追加式输出历史、祖先上下文、对比、搜索和请求幂等。数据库复合外键约束归属；版本冲突返回 409。

验证：累计 19 个 API 测试通过，包含并发保存、同请求重放、跨项目拒绝、分支隔离和版本保留。限制：搜索使用 SQLite 正文过滤，对比采用有界逐行替换，不保证最短编辑序列；上下文最多 256 个祖先、500,000 字符。

## 第三批：中文桌面

已实现 WPF 项目/员工/任务树、职责编辑、历史输入与角色快照、结果修正、复制修订、上下文、搜索、对比及项目密钥管理。复用原 MVVM 命令和主题；业务数据通过共享 C# HTTP 客户端保存。草稿按服务与任务链保存，输出草稿按记录保存；提交前持久化请求 ID，支持断线后检查与重试。

游戏演示含四个角色、六轮交接、两条玩法分支与一次输出修正；演示数据单独保存。启动脚本负责服务生命周期，关闭窗口后停止它自己启动的服务。

验证：21 个 API 测试与 1 个真实 WPF 工作流测试通过，包括完整停止服务后的恢复和响应丢失后的安全重试；Release 构建零警告，已检查实际窗口渲染。限制：桌面仅支持 Windows；草稿为本机单窗口文件，不提供多窗口合并；服务未运行时可保留草稿，业务查询仍需连接服务。

## 第四批：Agent 工具与可交付示例

已实现 C# CLI → HTTP 工具、函数定义、可安装 Skill 和完整执行示例。Agent 保存要求实际采用的员工定义版本，防止获取上下文后角色被修改导致快照错误。新增两项测试验证角色并发变化与同时追加结果的冲突；检索过滤条件也校验项目归属。

README 已转为新产品说明，附真实截图、Mermaid 数据关系/流程、启动与 API 调用步骤；原训练 README 与源代码保留。新增 Windows/Linux CI、SQLite 迁移检查、自包含 Windows 包和独立游戏验收脚本。

验证：23 个 API 测试与 1 个 WPF 工作流测试通过；原业务 49 个测试通过。真实工具验收创建 4 名员工、6 轮交接和分支，31 次调用验证幂等、冲突、历史输出对比及引用上下文；Skill 格式检查通过；自包含 win-x64 包生成成功，迁移模型无遗漏。

限制：工具通过宿主配置的 HTTP 服务访问，不包含模型提供商循环或 MCP server。云端 Agent 需部署者提供可达 HTTPS 网络与项目密钥。未创建公开服务、未自动运行多 Agent；本机草稿、数据库和密钥依赖系统文件权限保护。

验收补充：对比接口、桌面与 Agent 工具均支持指定输出历史版本，能够直接比较同一轮的 v2/v3；API 和 WPF 测试已增加实际差异断言。

启动兼容性修正：用户终端没有 `pwsh` 时，原启动说明无法执行。已验证系统自带的 Windows PowerShell 5.1 可以运行现有启动器；新增正式/演示双击入口，使用系统 PowerShell 的绝对路径，无需安装 PowerShell 7 或修改 PATH。控制台分隔符改用 ASCII，避免旧 PowerShell 的编码乱码。

便携 exe 交付：增加自包含 C# WinExe 启动器，发布目录提供 `PromptCrew.exe` 与 `PromptCrew-Demo.exe`。真实发布程序已通过正式版、演示版、默认端口占用、认证、桌面渲染、关闭后服务退出及不完整包错误提示的验证。验证时从系统目录启动，子进程 PATH 中不包含 dotnet；测试使用独立临时工作区。CI 增加同样的发布包检查，旧的 PowerShell 启动方式继续保留。
